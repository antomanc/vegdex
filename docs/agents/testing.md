# Testing

Run the full check before calling a change done:
- Build: `pnpm build`
- Typecheck: `pnpm typecheck`
- Test: `pnpm test`
- E2E: `pnpm test:e2e`

## Unit tests: Vitest
- Run: `pnpm test`
- Tests live next to the code they cover or in `tests/`, named `*.test.ts`.
- Write the failing test first, then the code. Mock only process boundaries (network, shell, clock).

## Golden ingredient lines
`packages/core/test/golden/ingredient-lines.json` pins 500 real ingredient lines from `recipes.full.json`: 300 random English lines, 100 hard cases (`A` risky vegan words, `B` alternatives and amounts, `C` lost qualifiers, `D` lost ingredients, `E` Italian grammar) and 100 Italian-source lines. Each entry stores the parsed fields that matter, the metric English and Italian renders, and a review status:
- `ok`: amount, unit, ingredient and qualifiers survive; output must not change.
- `unreviewed`: output is locked but not yet judged; output must not change.
- `known-bad`: output must stay as stored or reach `expected`; matching `expected` fails with a prompt to promote the line to `ok`.

`packages/ingest/test/golden-ingredients.test.ts` loads the real vocabulary the way `parse-diff` and `emit` do and runs in `pnpm test`.

Commands:
- `pnpm golden`: re-render every stored line and print changed output; writes nothing.
- `pnpm golden --update`: rewrite the stored output and regenerate `docs/review/italian-lines.md`. Review fields survive.
- `pnpm golden:select --data apps/web/public/data/recipes.full.json`: reselect the seeded sample (dry run); add `--update` to write it. The dataset is generated by `pnpm ingest emit`, not committed.
- After a fix, run `pnpm golden`, promote the fixed `known-bad` lines to `ok` in the golden file, then `pnpm golden --update`.

## Browser E2E: Playwright
- Run: `pnpm test:e2e` (specs in `e2e/`, config in `playwright.config.ts`).
- Results: `test-results/e2e.json` (Playwright's JSON report) has every test's status and errors, for agents and scripts.
- Replace the skipped starter spec with a real flow as soon as the first screen exists.
